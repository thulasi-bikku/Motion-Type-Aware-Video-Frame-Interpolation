Motion-Type-Aware Diagnostic Benchmarking and Targeted Correction of Video Frame Interpolation Models

A diagnosis-to-correction study — not a new VFI backbone.

• Motion categories derived from RAFT optical-flow descriptors  
• Lightweight residual correction network (9-channel input → residual + confidence mask)  
• Generic vs. rotation-targeted correction comparison  
• 3,601-clip evaluation (PSNR / SSIM / LPIPS)
